Task Blocks

A simple personal task app for Android, Windows and Mac.

Task Blocks shows each task as a coloured block that slowly ages from green to red, so old tasks stand out. It is a personal app, made for its owner's own use. It is not sold and has no accounts, adverts or tracking.

What it does

  • Tasks with due dates, categories, repeats, checklists and reminders.
  • List, calendar, Kanban board and priority matrix views, plus home-screen widgets on Android.
  • Sync between devices through the owner's own Dropbox.
  • Optional Google sign-in, so emails can become tasks and starred emails can be attached to tasks.

Google sign-in

When Google sign-in is turned on, the app reads the signed-in Gmail account directly from the device. There is no Task Blocks server. The app can read emails and change their labels and stars. It cannot send or delete email. The privacy policy explains exactly what is used and where it is kept.
